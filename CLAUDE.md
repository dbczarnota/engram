# brain — working inside the vault

This repo is a personal knowledge vault (also an Obsidian vault). When working HERE:

- **Conventions:** read `_meta/conventions.md` before structural changes.
- **Frontmatter is required** on every note (see conventions). Use `_meta/templates/`.
- **Recall is tiered:** start from `_meta/index.md`, then drill into matching pages.
- **Standards & lessons are created only on explicit user request** — never inferred.
- **ADR vs standard:** per-project decision vs cross-project rule. Don't conflate.
- **Keep the index current:** when you add a standard/lesson/project, add its one-line summary
  to `_meta/index.md`.
- **Archive, don't delete:** finished projects move to `archive/` via `/archive-project`.
- **Commit locally; never push** unless asked.
