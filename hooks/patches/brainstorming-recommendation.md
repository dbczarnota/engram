## Always Recommend When Presenting Options

Whenever you present the user with options, choices, or alternatives — at ANY point in
the conversation, not only the "Propose 2-3 approaches" step — you MUST include:

1. **Your recommendation** — state clearly which single option you would pick.
2. **Why it is the best** — concrete reasoning tied to the actual goal and constraints,
   not generic praise.
3. **Why each other option is worse** — name the specific tradeoff that loses for each
   rejected option. No vague hand-waving.

Never present a bare menu and ask the user to choose blind. A recommendation with solid
justification is required every time — even for small choices.
